# QEMU Assembly Toolkit

面向 QEMU 汇编开发的 VS Code 插件，目标是串联代码编写、构建、运行和调试。

## 当前状态

项目初始化阶段，当前已提供 TypeScript 插件入口、项目说明命令、扩展开发调试配置和 GitHub CI。汇编语言辅助、工具链检测、构建、QEMU 运行和 GDB 调试尚未实现。

首版暂定面向 **x86 + NASM + QEMU 系统模拟**，架构及语法支持可在实现前调整。

## 本地开发

需要 Node.js 22 和 VS Code 1.96 或更高版本。

```sh
npm ci
npm run check
npm run compile
```

用 VS Code 打开项目，按 F5 启动扩展开发宿主。在新窗口中打开命令面板，执行 `QEMU Assembly: 查看项目说明`。
