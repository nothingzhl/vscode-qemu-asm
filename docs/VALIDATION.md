## 兼容性追加验证（2026-10-15）

发现并修复以下问题：

- 镜像路径只比较字符串，可能通过大小写别名或项目内目录链接指向源码/配置。构建现在先比较文件实际身份；Linux 目录链接回归通过，大小写不敏感卷测试将由对应平台执行。
- 核心测试包含 POSIX 固定路径，已改为使用平台路径 API；新增 Windows 盘符/UNC/不同盘符、中文空格路径和 macOS/Linux 路径语义测试。
- 拒绝 `C:tool.exe` 等盘符相对路径，避免依赖进程的每盘当前目录。
- 输出流使用 UTF-8 连续解码，分块中文日志不会损坏文件路径。
- 区分插件主动停止与异常信号终止；后者显示运行失败。

## 0.7.1 原生调试刷新与功能录屏

在实际录制 C 原生单步与调用栈切换时，发现 VS Code 会在新暂停后继续请求上一暂停的帧作用域。旧帧作用域现在返回空列表，旧帧求值仍明确失败且不弹出全局通知，不会读取或冒充新帧的数据。新增回归验证旧请求不访问 GDB、不分配句柄，当前帧和调用者的变量仍分别属于对应帧。217 项单测中 216 项通过、1 项文件系统条件跳过；类型检查、编译、真实 C 源码集成，以及 VS Code 1.96.4 / 1.142.0 的 C 宿主验证通过。
